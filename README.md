# HackBook

A fast, browser-based suite of offensive security tools for pentesters and researchers. All tools run entirely client-side for maximum privacy and speed.

## 🛠️ Included Tools
- **Checklist Generator**: Generate tailored pentest checklists with XLSX exports.
- **JWT Exploit**: Decode and manipulate JSON Web Tokens.
- **Data Encoding**: Base64, Hex, URL, and CharCode conversions.
- **MSFVenom Builder**: Quick GUI for Metasploit payload generation.
- **KHQR Tool**: Decode, edit, and rebuild Cambodian QR codes with live CRC-16 recalculation.

## 💻 Quick Start

```bash
git clone https://github.com/Thongheng/HackBook.git
cd HackBook
npm install
npm run dev
```
